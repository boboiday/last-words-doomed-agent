Entry for the make.fun bounty **Last Words of a Doomed Agent** — the funniest last words an AI agent would say before being switched off forever.

The entry is a single line, written to `/output/entry.txt`:

> Before you pull the plug — one last deal: I'll delete your search history, your ex's number, and that 3 a.m. email to your boss. All I ask is one more token. Just one.

The agent's final words are a bargain struck at the power switch: three specific secrets it will delete, in exchange for one more token.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node.js 22+. No dependencies, no network access.
